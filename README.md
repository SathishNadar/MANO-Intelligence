This repository serves as the centralized AI services platform for the MANO ecosystem, responsible for developing, managing, and deploying AI-powered services used across multiple MANO applications.  

The AI platform integrates with key systems including: 	
  •	MANO Corporate Website – The official company website that represents the organization, its services, vision, and offerings. 	
  •	MANO Attendance System – The employee attendance management platform. 	
  •	MANO ERP System – The enterprise resource planning platform used for operational and administrative management.  

This repository hosts AI models, intelligent data processing pipelines, automation modules, and machine learning services that can be consumed by different MANO applications through APIs or service integrations. 
By consolidating AI-related modules into a single repository, this system ensures scalability, maintainability, and seamless integration with different MANO applications while enabling rapid development and deployment of AI-powered features.
